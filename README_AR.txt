Night Auditor Assistant v2.0
=============================

المزايا الجديدة:
- مؤشرات Occupancy و ADR و RevPAR (بناءً على مداخيل الغرف المدخلة يدوياً وعدد الغرف المشغولة/المتاحة).
- سجل مناوبات محفوظ محلياً مع ملخصات.
- تصدير نسخة احتياطية JSON واستيرادها لاسترجاع البيانات.
- فصل تصنيفات العمليات وطرق الدفع لاحتساب النقدية بدقة أكبر.
- تقرير نهاية مناوبة موسع وقابل للطباعة/الحفظ PDF.
- إدارة مهام وتذكيرات أثناء تشغيل التطبيق.
- PWA للعمل دون اتصال بعد فتحه أول مرة عبر HTTPS.

التشغيل والتثبيت:
1. فك ضغط ZIP.
2. للتثبيت والعمل دون إنترنت بشكل أفضل، استضف الملفات على HTTPS أو استخدم خادماً محلياً موثوقاً.
3. افتح الرابط في Chrome على Android أو Chrome/Edge على Windows.
4. اختر تثبيت التطبيق / إضافة إلى الشاشة الرئيسية.
5. فعّل إشعارات المتصفح.

قيود مهمة:
- لا يوجد تزامن تلقائي بين الهاتف والحاسوب. انقل نسخة JSON يدوياً بينهما.
- إشعارات المواعيد تفحص أثناء تشغيل التطبيق؛ لا نضمن التنبيه بعد إغلاقه أو إيقاف الجهاز.
- ADR = إيراد الغرف ÷ عدد الغرف المشغولة المدخل.
- RevPAR = إيراد الغرف ÷ إجمالي الغرف المتاحة المدخل.
- هذه مؤشرات مبسطة لفترة المناوبة وليست بالضرورة المؤشرات المحاسبية النهائية للفندق؛ استخدم عدد الغرف/ليالي الغرف المطابق لفترة التقرير.
- لا تدخل بيانات بطاقات أو وثائق حساسة. لا يتصل البرنامج بنظام PMS ولا ينفذ Night Audit آلياً.
- راجع كل الحسابات وإجراءات الفندق الرسمية قبل اعتماد التقرير.

النسخة 2.0 - أداة مساعدة وليست نظاماً محاسبياً معتمداً.
