# Night Audit Manager Pro v3
واجهة تأسيسية متعددة الفنادق والرياضات مرتبطة بـ Supabase.

## قبل النشر
- ضع مفتاح Supabase Publishable الحالي في `app.js`.
- لا تضع أي مفتاح Secret أو service_role في ملفات الواجهة.
- راجع `SETUP_AR.txt` قبل النشر.

## الملفات
- `index.html`: واجهة تسجيل الدخول وإدارة المؤسسات والعمليات.
- `app.js`: اتصال Supabase.
- `style.css`: التصميم.
- `SETUP_AR.txt`: خطوات الإعداد وحدود الإصدار.
